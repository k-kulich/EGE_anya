## Типы данных

Основные типы данных в питоне:
```python
str  # строка - по сути массив символов
int  # целое число
float  # число с плавающей точкой (дробное)
bool  # логическое значение (0|1, т.е. True|False)
```

Кроме них есть более сложные структуры: списки, кортежи, множества, словари – о них позже.

## Как с ними работать

Python - не строготипизированный язык программирования. Что это значит? Только то, что нам не нужно объявлять тип переменной, когда мы
ее создаем. Чтобы создать переменную, достаточно просто задать ей начальное значение. Это одновременно и удобно, и не очень, но
что ж поделать :)

Из-за динамической типизации переменная может менять тип в ходе программы, что иногда приводит к ошибкам. Поэтому при преобразовании типов (то есть когда мы хотим изменить тип данных переменной, например, из строки `'10'` в число `10`) лучше создавать новую переменную.

## Целые числа (int)

Остановимся подробнее сначала на целых числах. Как уже сказано выше, для того, чтобы создать целочисленную переменную, не нужно
(как, например, в C/C++ и других строготипизированных языках) сначала ее объявлять и указывать ее тип, а уже потом присваивать
значение: здесь это делается одновременно, объявление и присваивание за одну операцию. Разница наглядно:

```cpp
// в С/С++ мы бы сделали так:
int my_variable;  // объявили переменную
my_variable = 15;  // присвоили ей значение 15
// теперь my_variable = 15.5 вернет CompileError, потому что my_variable может быть только целым числом
```
```python
# в питоне же мы бы сделали так
my_variable = 15  # мы создали переменную типа int, в которой хранится число 15
# если написать int my_variable, а потом присвоить значение, то будет SyntaxError - питон такое не умеет
```

Так какие в нестрогой типизированности минусы, если просто запись сокращается? Все очень просто: из-за того, что созданная нами 
переменная не обязана хранить данные только одного типа, мы можем преобразовать их к другому, и это никак не будет явно видно
в коде, если только мы это не пометим комментарием или логом. И может получиться так, что мы думали, что в переменной лежит число,
а на самом деле уже строка... ну и не заработает у нас тогда ничего, скорее всего. Так что для преобразования в другой тип данных
лучше создавать новую переменную, чтобы не запутаться и не насоздавать будующему себе проблем.

### Действия с целыми числами

```python
# их можно: складывать, вычитать, умножать, возводить в степень, делить (нацело, просто и с остатком) 
a = 5
b = 3
# сложение
a + b  # комп посчитает и никуда не запомнит
c = a + b   # сумма a и b сразу запишется в переменную c
# возведение в степень
d = a ** 2  # это мы записываем в d значение, равное a в квадрате
h = a ** 0.5  # вот так мы можем взять корень (по свойствам степеней)
# деление
s = a / b  # в s будет переменная типа float (тк это просто математическое деление)
m = a // b  # это целочисленное деление, то есть m - это целая часть от деления (без остатка)
n = a % b  # это взятие остатка от деления (то есть n - ост от деления a на b)
```

## Логические данные (bool)
*bool* - тип данных, у которого 2 значения: `True` или `False`

```python
a = True
a = True or False  # логические операторы И, ИЛИ, НЕ при применении вернут тип bool
# все базовые логические операции доступны - and, or, not
c = not a          # False

int(True)           # 1
int(False)          # 0
int(a)  # даст нам численное представление логической переменной, то есть 1 при True, 0 при False
```

_Кстати, интересный факт_: импликация может быть в питоне заменена знаком `<=`, и это будет работать! Доказать это можно через таблицы
истинности, и оно действительно так работает. То есть к базовым операциям также без проблем добавляются эквивалентность и импликация.

## Строки (str)

Строки – это упорядоченные последовательности символов. Их можно создавать в одинарных или двойных кавычках.

```python
s1 = 'Привет'
s2 = "мир"
s3 = '''Многострочная
строка'''
```

### Основные операции со строками

```python
# Конкатенация (склеивание)
s = s1 + ' ' + s2       # "Привет мир"

# Повторение
s = 'ha' * 3            # "hahaha"

# Длина строки
n = len(s)              # 6

# Доступ по индексу (нумерация с 0)
first = s[0]            # 'h'
last = s[-1]            # 'a'

# Срезы [start:stop:step]
sub = s[1:4]            # символы с индексами 1,2,3 → "aha"
rev = s[::-1]           # разворот строки

# Поиск подстроки
if 'ha' in s:
    print('Нашли!')

# Основные методы
s.upper()               # верхний регистр
s.lower()               # нижний регистр
s.strip()               # удалить пробелы в начале и конце
s.replace('a', 'o')     # замена символов
s.split(',')            # разделить по разделителю (вернет список)
','.join(['a','b','c']) # собрать строку из списка
```

## Помни разницу в операторах!

Есть две штуки, которые часто путаются, а путать их нельзя. Оператор присваивания - это оператор (значок), который позволяет записать
какое-то значение в переменную или (в случае изменяемых типов данных) изменить уже записанное. Оператор сравнения - это операция
эквивалентности, то есть просто сравнение. Оно никуда не записывает и возвращает только логический результат. В питоне, как и, к слову, во многих популярных языках, эти операторы очень похожи, поэтому надо быть осторожными и не путаться:

```python
# 1 равно - это оператор присваивания
delta = 0.5  

# 2 равно - это сравнение 
m == n  # сравниваем переменные

# другие знаки сравнения: >, <, ==, >=, <= 
```

## Условные конструкции

Условные конструкции - это блоки для построения условий. Не всегда же у нас все может идти по одному и тому же сценирию, а 
условные конструкции помогают нам учесть различные варианты развития событий. В отличие от большинства языков, питон не ограничивается
одним `if-else`: в конструкции может быть сколько угодно блоков `elif` для того, чтобы проверить дополнительные условия. Такая фича
вообще добавлена из-за того, что в питоне блоки кода, находящиеся в разных областях видимости (о них чуть позже), располагаются
на разном количестве пробелов от начала строки, из-за чего большое количество вложенных друг в друга `if-else` становится просто нечитаемым.

Вот так могут выглядеть условные конструкции в Python:
```python
if a:  # могут состоять только из 1 условия
    pass  # +4 отступа для кода, который выполняется при выполнении условия

if a:
    pass  
else:  # добавляется блок "иначе" для всех случаев, не подходящих под условие
    pass
```

Обрати внимание на _обязательные отступы (4 пробела)_ – они определяют блок кода.

Теперь для примера напишем программу, которая распознает погоду, которую вводит пользователь с помощью команды
`input()`, которая возвращает строку, которую ввел пользователь при запуске программы (строку до нажатия на `<Enter>`):

```python
weather = input()  # считаю с клавиатуры погоду
if weather == "ясно":  # проверяю, что погода ясная
    print("ураа солнце!")
else:
    print("о нет, дождь(")
```

НО! наша программа сейчас умеет обрабатывать только солнечную погоду. А если будет снег? Она скажет, что дождь, а это неправда.
Доработать ее мы сможем как раз-таки с помощью `elif`:

```python
if a:
    pass
elif a and True:  # if + else, то есть условие, которое проверяется, если не подошло предыдущее
    pass
else:
    pass
```

Теперь используем `elif` в нашем коде, чтобы предусмотреть варианты другой погоды:

```python
weather = input()  # считаю с клавиатуры погоду
if weather == "ясно":
    print("ураа солнце!")
elif weather == "снег":
    print("снег...")
elif weather == "град":
    print("какой ужас! град!")
else:
    print("о нет, дождь(")
```

## Циклы

Циклы - очень полезная штука, облегчающая разработку. Как можно понять из названия, эти конструкции "зацикливают" блок кода, то есть заставляют его повторяться несколько раз. Это куда удобнее, чем дублировать его по несколько раз. В питоне есть 2 основных цикла - это `for` и `while`.

### Цикл `for`

А что, если мы захотим, чтобы программа обрабатывала данные не только за один день, а за всю неделю разом? Для этого нам нужно, чтобы мы могли 7 раз ввести погоду, но повторять такой блок кода 7 раз слишком неэкономично, поэтому мы используем цикл. В принципе их суть - это повторение блока кода несколько раз (заданное заранее или не заданное количество повторений).

Для того, чтобы повторить блок кода заданное количество раз, удобнее всего использовать цикл `for` - он нужен для того, чтобы перебирать какие-то заранее известные значения. Мы же знаем, что в неделе 7 дней, а значит если `for` пройдется по всем числам от 0 до 7 (не включительно), то он переберет их ровно 7, а вместе с тем повторит блок кода 7 раз - то есть вместо дублирования через `ctrl+c` - `ctrl+v` мы напишем еще 1 строку кода, и сможем считать данные за целую неделю:

```python
for i in range(7):  # цикл, который повторит наш код 7 раз
    weather = input()
    if weather == "ясно":
        print("ураа солнце!")
    elif weather == "снег":
        print("снег...")
    elif weather == "град":
        print("какой ужас! град!")
    else:
        print("о нет, дождь(")
```

Сам перебор чисел происходит с помощью функции `range`, которая генерирует числа в заданном диапазоне [start; stop) с шагом step.

! __Важно__: она принимает в качестве параметров (то есть границ диапазона и шага) только целые числа, то есть тип int. Если попытаться подставить что-нибудь другое, то получится ошибка.

```python
# как можно задать range:
range(stop) # -- генерирует все значения (целочисленные, то есть типа int) от 0 до stop (stop не включительно)
range(start, stop) # -- генерирует все значения (целочисленные, то есть типа int) от start до stop (stop не включительно)
range(start, stop, step) # -- генерирует все значения (целочисленные, то есть типа int) от start до stop с шагом step (stop не включительно)
```

Сама функция при этом возвращает так называемый генератор, который работает как однонаправленный итератор - то есть объект, элементы которого можно перебрать только в 1 порядке и только 1 раз, потому что он не хранит числа, а генерирует последовательность на ходу.

```python
range(0, 11, 2)  # сгенерирует 0 2 4 6 8 10
```

Эта функция чаще всего используется в связке с циклом for, когда нужно перебрать какой-то набор чисел или же сгенерировать определенное количество повторений.

```python
for _________ in range(start, stop[, step])  # -- классическое использование цикла for
```

В самом цикле `for` необходимо задать переменную, которая и будет перебирать значения в генерируемом диапазоне, а как ее назвать - это уже дело личного удобства. В целом есть общепринятые правила по именованию переменных: если они временные и не очень-то нужные (например, цикл создан только для повторения заданное число раз, и само значение числа на каждом повторении - итерации - не очень-то нужно), то как правило переменную называют одной буквой. Если же переменная используется дальше в коде, то, чтобы не запутаться, лучше назвать ее так, чтобы при взгляде на нее тебе сразу было понятно, что ты в ней хранишь. Например, в случае перебора чисел с помощью цикла `for`, если ты делаешь какие-то действия с этим числом, можно сделать так:

```python
for number in range(start, stop):
    ... # какой-то код, в котором используется number
```

Вообще `for` используется для перебора последовательностей (строк, списков, диапазонов чисел).

### Цикл `while`

Цикл `while` повторяет блок, пока условие истинно.

```python
count = 0
while count < 5:
    print(count)
    count += 1

# Осторожно! Если условие всегда истинно, цикл станет бесконечным.
```

### Управление циклом:

- `break` – досрочный выход из цикла
- `continue` – переход к следующей итерации

```python
for i in range(10):
    if i == 3:
        continue          # пропустить 3
    if i == 7:
        break             # остановиться на 7
    print(i)              # 0 1 2 4 5 6
```

## Списки (list)

Список – упорядоченная изменяемая коллекция элементов (сами элементы могут быть разных типов).

```python
# Создание
empty = []
numbers = [1, 2, 3, 4, 5]
mixed = [1, "два", 3.0, True]

# Доступ по индексу
print(numbers[0])      # 1
print(numbers[-1])     # 5 (последний)

# Срезы (как у строк)
print(numbers[1:4])    # [2, 3, 4]
print(numbers[::-1])   # разворот

# Изменение элемента
numbers[2] = 100

# Добавление
numbers.append(6)      # добавить в конец
numbers.insert(2, 99)  # вставить на позицию 2

# Удаление
x = numbers.pop()      # удалить последний и вернуть его
del numbers[2]         # удалить по индексу
numbers.remove(100)    # удалить первое вхождение значения

# Длина списка
n = len(numbers)

# Проверка наличия
if 2 in numbers:
    print("Есть двойка")

# Перебор элементов
for item in numbers:
    print(item)

# Перебор с индексами
for i, val in enumerate(numbers):
    print(i, val)

# Генераторы списков (list comprehension)
squares = [x**2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]
```

## Кортежи (tuple)

Кортеж – упорядоченная неизменяемая коллекция. Отличается от списка тем, что его нельзя изменить после создания. Отсюда следует, что элементами кортежа не могут быть изменяемые типы данных (вроде списков и словарей), в то время как, например, список может состоять из других списков.

```python
# Создание
t = (1, 2, 3)
single = (5,)          # кортеж из одного элемента (обязательна запятая)
empty = tuple()        # пустой кортеж

# Доступ как в списке
print(t[0])            # 1
# t[0] = 10            # Ошибка! Кортеж неизменяем

# Упаковка и распаковка
point = (10, 20)
x, y = point           # x=10, y=20

# Преобразование
lst = list(t)          # кортеж → список
t2 = tuple(lst)        # список → кортеж
```

## Множества (set)

Множество – неупорядоченная коллекция уникальных элементов. Позволяет быстро проверять принадлежность и выполнять операции над множествами (объединение, пересечение и т.д.). То есть работает как математическое множество.

```python
# Создание
s = {1, 2, 3, 3, 2}    # будет {1, 2, 3}
empty_set = set()      # пустое множество (не {}, это словарь)

# Добавление и удаление
s.add(4)
s.remove(2)            # если элемента нет – ошибка
s.discard(10)          # удаляет, если есть, иначе ничего не делает

# Проверка
if 3 in s:
    print("3 есть в множестве")

# Операции над множествами
a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)           # пересечение {2, 3}
print(a | b)           # объединение {1, 2, 3, 4}
print(a - b)           # разность {1}
print(a ^ b)           # симметрическая разность {1, 4}

# Перебор (порядок не гарантирован)
for x in a:
    print(x)
```

## Словари (dict)

Словарь – неупорядоченная коллекция пар «ключ – значение». Ключи должны быть уникальными и неизменяемыми (числа, строки, кортежи).

```python
# Создание
person = {"name": "Анна", "age": 17, "city": "Москва"}
empty_dict = {}

# Доступ по ключу
print(person["name"])
print(person.get("phone", "нет номера"))   # безопасный доступ с запасным значением

# Изменение и добавление
person["age"] = 18
person["grade"] = 11

# Удаление
del person["city"]
age = person.pop("age")    # удалить и вернуть значение

# Проверка наличия ключа
if "name" in person:
    print("Имя есть")

# Перебор
for key in person:
    print(key, person[key])

for key, value in person.items():
    print(f"{key}: {value}")

for value in person.values():
    print(value)

# Длина словаря
n = len(person)
```

## Ввод и вывод данных

**Вывод на экран**

```python
print("Привет, мир!")
print("Ответ:", 42, sep=" ", end="\n")   # sep – разделитель, end – окончание
```

**Ввод с клавиатуры**

## Работа с файлами

### Текстовые файлы

Из текстовых файлов извлекаются строки - тип `str`, даже если там записаны числа. Точно также и записывать в файлы мы можем только строки.

**Чтение из файла**
```python
# Прочитать всё содержимое
with open("input.txt", "r", encoding="utf-8") as f:
    data = f.read()
    print(data)

# Построчное чтение
with open("input.txt", "r", encoding="utf-8") as f:
    for line in f:
        line = line.rstrip("\n")   # удалить символ перевода строки
        print(line)
```

**Запись в файл**
```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Строка 1\n")
    f.write("Строка 2\n")
```

Режимы: `"r"` – чтение, `"w"` – запись (перезаписывает), `"a"` – добавление в конец.

### CSV-файлы

Для работы с табличными данными удобно использовать встроенный модуль `csv`.

**Чтение CSV**
```python
import csv

with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f, delimiter=",")   # или delimiter=";"
    for row in reader:
        print(row)          # row – список строк

# Если первая строка – заголовки
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f, delimiter=",")
    for row in reader:
        print(row["Имя"], row["Возраст"])
```

**Запись CSV**
```python
import csv

data = [["Имя", "Возраст"],
        ["Анна", 18],
        ["Иван", 17]]

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, delimiter=",")
    writer.writerows(data)
```

Содержит математические функции и константы.

### Модуль itertools

Инструменты для комбинаторики и итераторов. Очень полезен в задачах ЕГЭ (номера 2, 8 и 26).

```python
import itertools

# Перестановки (размещения без повторений)
items = [1, 2, 3]
perms = itertools.permutations(items, 2)   # все упорядоченные пары
print(list(perms))   # [(1,2), (1,3), (2,1), (2,3), (3,1), (3,2)]

# Сочетания (порядок не важен)
combs = itertools.combinations(items, 2)
print(list(combs))   # [(1,2), (1,3), (2,3)]

# Сочетания с повторениями
combs_wr = itertools.combinations_with_replacement(items, 2)
print(list(combs_wr)) # [(1,1), (1,2), (1,3), (2,2), (2,3), (3,3)]

# Декартово произведение (аналог вложенных циклов)
prod = itertools.product([1,2], ["a","b"])
print(list(prod))   # [(1,'a'), (1,'b'), (2,'a'), (2,'b')]

# Бесконечные итераторы
for i in itertools.count(5, 2):   # 5, 7, 9, ...
    if i > 15:
        break

# Группировка данных (полезна для задачи 26)
data = [1,1,1,2,2,3,3,3,3]
groups = itertools.groupby(data)
for key, group in groups:
    print(key, list(group))
```

### Модуль turtle

Графический модуль для рисования. Используется в задании 6 ЕГЭ (исполнитель Черепаха).

```python
import turtle

t = turtle.Turtle()           # создаём черепашку
t.speed(5)                    # скорость 
t.pensize(3)                  # толщина линии
t.pencolor("blue")            # цвет пера

# Основные команды
t.forward(100)                # вперёд на 100 пикселей
t.backward(50)                # назад на 50 пикселей
t.right(45)                   # поворот направо на 45 градусов
t.left(90)                    # поворот налево на 90 градусов
t.goto(50, 50)                # переместиться в точку (x, y)
t.penup()                     # поднять перо (не рисовать)
t.pendown()                   # опустить перо
t.dot(20, "red")              # точка радиусом 20 пикселей, красная
t.circle(40)                  # окружность радиусом 40 пикселей
t.circle(40, 180)             # полуокружность

# Заливка
t.fillcolor("yellow")
t.begin_fill()
for _ in range(4):
    t.forward(100)
    t.left(90)
t.end_fill()

# Настройка окна
turtle.screensize(600, 600)
turtle.bgcolor("lightblue")
turtle.title("Моя черепашка")

turtle.mainloop()             # чтобы окно не закрылось сразу после окончания движения черепашки
```
